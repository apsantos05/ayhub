# Texto para portfolio

## AY Hub

Desenvolvi o AY Hub, um painel web para gestao operacional da AY Social Media. O sistema centraliza clientes, propostas, financeiro, tarefas, calendario de conteudo, estudos e controle de usuarios em uma interface estilo SaaS.

O projeto foi construido com React, Vite, Node.js, Express e SQLite. No back-end, implementei uma API REST com persistencia em banco local, autenticacao por usuarios e senhas com hash, rotas CRUD e endpoint de status do banco. No front-end, desenvolvi uma interface responsiva com sidebar, dashboard de indicadores, formularios reutilizaveis, tabelas gerenciais e fluxos de cadastro/edicao/exclusao conectados ao banco.

O codigo-fonte e privado por conter regras internas do produto, mas a demonstracao visual e funcional pode ser apresentada por prints, video ou ambiente de demo.

## Principais aprendizados

- Modelagem de dados com SQLite
- Integracao front-end/back-end via API REST
- Organizacao de componentes React reutilizaveis
- Controle de usuarios e login
- Design de painel SaaS para uso real em rotina de agencia
