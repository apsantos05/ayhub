# AY Hub

Painel pessoal e profissional para gestao da agencia AY Social Media.

> Este repositorio de vitrine nao contem o codigo-fonte completo do produto. O codigo principal e privado por conter regras internas, estrutura de banco e logica operacional da agencia.

## Visao geral

O AY Hub e um sistema web estilo SaaS criado para centralizar a rotina de uma agencia de social media. Ele organiza clientes, propostas, contratos, financeiro, calendario de conteudo, tarefas, estudos e geracao local de ideias de posts.

## Stack

- React
- Vite
- Node.js
- Express
- SQLite
- REST API
- Autenticacao com usuarios e senhas com hash

## Modulos

- Dashboard com indicadores principais
- Clientes com cadastro, edicao, exclusao, busca e filtro por status
- Propostas com texto pronto para WhatsApp e impressao em PDF pelo navegador
- Financeiro com receitas, despesas, pendencias e lucro estimado
- Calendario de conteudo por cliente, data, tipo e status
- Tarefas com prioridade, prazo e conclusao
- Estudos com horas semanais e progresso por area
- Gerador de ideias de posts com regras locais
- Usuarios para socios e funcionarios
- Configuracoes da agencia

## O que eu desenvolvi

- Arquitetura separada entre front-end e back-end
- API REST em Express
- Banco SQLite com tabelas relacionais
- Interface responsiva com sidebar
- Fluxos CRUD persistidos no banco
- Login baseado em usuarios no banco
- Tela de status do banco de dados
- Geracao local de ideias sem depender de IA paga
