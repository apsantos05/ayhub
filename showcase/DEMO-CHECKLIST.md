# Checklist para demonstracao

Use este roteiro para gravar um video curto ou apresentar o AY Hub ao vivo.

1. Login
   - Mostrar tela de entrada.
   - Entrar com usuario admin.

2. Dashboard
   - Mostrar cards de clientes, previsao mensal, pendencias, tarefas e propostas.

3. Clientes
   - Criar cliente de exemplo.
   - Editar status.
   - Filtrar por status.

4. Propostas
   - Criar uma proposta.
   - Gerar texto para WhatsApp.
   - Abrir impressao/PDF.

5. Financeiro
   - Registrar entrada.
   - Registrar saida.
   - Mostrar lucro estimado.

6. Conteudos
   - Criar conteudo.
   - Marcar como postado.

7. Tarefas
   - Criar tarefa.
   - Concluir tarefa.

8. Estudos
   - Registrar estudo.
   - Mostrar progresso por area.

9. Usuarios
   - Mostrar que e possivel cadastrar socia ou funcionario.

10. Configuracoes
   - Mostrar dados da agencia e status do banco SQLite.
